利用の流れと支払い方法

申し込み、事前確認、当日利用、支払い、定期利用、支援制度、何でも屋ハウスの流れをまとめています。

はじめに確認すること

利用したい内容が決まっている場合は、サービス一覧と料金シミュレーターで対象サービス、基本料金、プレミアム料金、移動代金の目安を確認します。内容が未確定の場合でも、お問い合わせフォームから相談できます。

  • 日常作業、相談、業務補助、子ども向け、シニア向けの依頼は主要5サービスから選びます。
  • 継続利用したい場合はNanndemoya365、クラウド導入やGoogle Workspace運用はNanndemoyaCloudを確認します。
  • 料金は基本料金・プレミアム料金と、移動代金、道具代金、宿泊代金などのオプション料金を分けて確認します。

主要5サービスとNanndemoya365

  1. 申し込みフォームまたはお問い合わせフォームから、希望するサービス、日時、場所、依頼内容を送信します。
  2. 何でも屋からの返信で、対応可否、作業内容、料金条件、支払い方法を確認します。
  3. 内容が確定したら申し込み完了です。依頼日の前日までに、行きの移動代金を支払います。
  4. 依頼日当日、指定場所でサービスを利用します。
  5. サービス終了後、利用料金とオプション料金を支払います。事前に支払った行きの移動代金は除きます。
  6. 支払い確認後、領収書を受け取って完了です。

Nanndemoya365はベースパックでの支払いが基本です。利用料金やオプション料金は、事前入金が必要になる場合があります。

定期利用・クラウド

NanndemoyaCloud

  1. フォームから導入または利用を申し込みます。
  2. 見積書兼請求書を受け取り、記載期限までに指定口座へ振り込みます。
  3. 入金確認後、利用開始手続きが行われ、完了後に通知されます。
  4. 初回以降は原則として毎月28日までにベースパックへ入金します。
  5. 入金確認後、サービス利用が継続されます。

MacStudioShere’s

PC基金で購入予定のMac Studioをリモート接続で利用する予定のサービスです。提供開始後に申し込み方法、利用条件、支払い方法が掲載されます。

支援制度・何でも屋ハウス

ライフイベント支援

  1. フォームから支援内容を申し込みます。
  2. 対象要件を確認するための審査が行われます。
  3. 審査通過後、指定された方法で入金状況を確認します。
  4. 何でも屋から連絡が届いた場合は、速やかに返信します。

何でも屋ハウス

  1. 申し込みフォームから物件提供の希望を送信します。
  2. 詳細情報の確認依頼に返信します。
  3. 物件見学、査定、オプション確認の日時を調整します。
  4. 見学、査定、オプション項目の確認を実施します。
  5. 条件確認後、利用開始手続きに進みます。

何でも屋ハウスの査定は第三者の査定業者などが行う場合があるため、完了まで時間がかかることがあります。

支払い方法

  • 現金：サービス内容によって利用できる場合があります。
  • 口座振り込み：NanndemoyaCloudの初回支払いなどで利用されます。
  • PayPal：一部決済で手数料相当額が加算される場合があります。
  • ベースパック：定期利用やクラウドサービス、基金関連の支払い管理に使われるデポジット型の決済基盤です。
  • ベースパッククレジット：基金参加などで付与され、基本料金や一部サービスの通常基本料金に充当できます。オプション料金には利用できません。
