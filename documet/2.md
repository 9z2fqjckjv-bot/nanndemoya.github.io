はい、可能です。Google Apps Script（GAS）の\*\*「ウェブアプリ（Web App）」\*\*という機能と`HtmlService`を使うことで、専用のWebページ（HTMLフォーム）を作成し、そこから入力されたデータをスプレッドシートに自動で追加するシステムを構築できます。

この方法を使えば、スプレッドシートの編集権限がないユーザーでも、Webページから安全にデータを追加できるようになります。

以下に、簡単な入力フォームを作成し、「転記先シート」にデータを追加するためのコードと手順をご案内します。

### 1\. GASエディタにコードを記述する

GASのエディタ（拡張機能 ＞ Apps Script）を開き、以下の2つのファイルを作成・編集します。

#### ① `コード.gs` （バックエンド処理）

最初からある `コード.gs` の中身をすべて消して、以下のコードを貼り付けます。

``` javascript
// Webページ（URL）にアクセスしたときにHTMLを表示する関数
function doGet() {
  return HtmlService.createHtmlOutputFromFile('index')
      .setTitle('利用申込フォーム')
      .addMetaTag('viewport', 'width=device-width, initial-scale=1'); // スマホ対応
}

// HTMLのフォームから送信されたデータを受け取り、シートに追加する関数
function processForm(formObject) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName("転記先シート");
  
  if (!sheet) {
    throw new Error("「転記先シート」が見つかりません。");
  }
  
  // フォームの入力内容を配列にしてシートの最終行に追加
  // ※実際の列の順番に合わせてformObjectのプロパティを並べてください
  const rowData = [
    formObject.name,      // A列: 名前 (sample)
    formObject.email,     // B列: メール (sample@nanndemoya.site)
    formObject.phone,     // C列: 電話番号 (7090758210)
    formObject.date,      // D列: 日付 (20260101)
    formObject.houseType, // I列: 住居タイプ (一軒家) など
    // 必要に応じてフォームのname属性と合わせて追加してください
  ];
  
  sheet.appendRow(rowData);
  
  return "お申し込みが完了しました！";
}

```

#### ② `index.html` （フロントエンドのWebページ）

1.  エディタ左上の「＋」ボタン（ファイルを追加）をクリックし、「HTML」を選択します。
2.  ファイル名を `index` と入力して作成します。
3.  以下のコードを貼り付けます。

``` html
<!DOCTYPE html>
<html>
  <head>
    <base target="_top">
    <style>
      body { font-family: sans-serif; padding: 20px; max-width: 400px; margin: auto; }
      label { display: block; margin-top: 10px; font-weight: bold; }
      input, select { width: 100%; padding: 8px; margin-top: 5px; box-sizing: border-box; }
      button { margin-top: 20px; padding: 10px 20px; background-color: #4CAF50; color: white; border: none; cursor: pointer; width: 100%; }
      button:hover { background-color: #45a049; }
      #message { margin-top: 15px; font-weight: bold; text-align: center; }
    </style>
    <script>
      // フォーム送信ボタンが押されたときの処理
      function handleFormSubmit(formObject) {
        // 送信ボタンを無効化して二重送信を防ぐ
        document.getElementById('submitBtn').disabled = true;
        document.getElementById('submitBtn').innerText = "送信中...";
        document.getElementById('message').innerText = "";

        // GASの processForm 関数を呼び出す
        google.script.run
          .withSuccessHandler(function(msg) {
            document.getElementById('message').style.color = "green";
            document.getElementById('message').innerText = msg;
            document.getElementById('myForm').reset(); // フォームをクリア
            resetButton();
          })
          .withFailureHandler(function(err) {
            document.getElementById('message').style.color = "red";
            document.getElementById('message').innerText = "エラーが発生しました: " + err.message;
            resetButton();
          })
          .processForm(formObject);
      }

      function resetButton() {
        document.getElementById('submitBtn').disabled = false;
        document.getElementById('submitBtn').innerText = "送信する";
      }
    </script>
  </head>
  <body>
    <h2>利用申込フォーム</h2>
    <!-- フォーム送信時にデフォルトの画面遷移を防ぎ、JavaScriptの関数を呼ぶ -->
    <form id="myForm" onsubmit="event.preventDefault(); handleFormSubmit(this);">
      
      <label for="name">お名前</label>
      <input type="text" id="name" name="name" required>
      
      <label for="email">メールアドレス</label>
      <input type="email" id="email" name="email" required>
      
      <label for="phone">電話番号</label>
      <input type="tel" id="phone" name="phone">

      <label for="date">希望日</label>
      <input type="date" id="date" name="date">

      <label for="houseType">住居タイプ</label>
      <select id="houseType" name="houseType">

        <option value="マンション">マンション</option>

      </select>
```

### 2\. ウェブアプリとして公開する手順

コードを保存したら、インターネット上に公開してURLを発行します。

1.  GASエディタの右上にある青い **「デプロイ」** ボタンをクリックし、**「新しいデプロイ」** を選択します。
2.  左上の歯車アイコン（⚙️）をクリックし、**「ウェブアプリ」** を選択します。
3.  設定項目を以下のように指定します：
      * **説明:** （任意）例：「利用申込フォームv1」
      * **実行するユーザー:** **「自分（あなたのGoogleアカウント）」** （※これが重要です。これにより、アクセスした人がスプレッドシートの編集権限を持っていなくても、あなたの権限で書き込みが行われます）
      * **アクセスできるユーザー:** **「全員」** （Googleアカウントを持っていない人にも公開する場合）
4.  **「デプロイ」** をクリックします。
5.  （初回のみ）「アクセスを承認」という画面が出たら、ご自身のアカウントを選択し、「詳細」＞「（安全ではないページ）へ移動」＞「許可」の順に進めてください。
6.  デプロイが完了すると、**「ウェブアプリのURL（`https://script.google.com/macros/s/.../exec`）」** が発行されます。このURLをコピーしてください。

### 3\. 動作確認

コピーしたURLをブラウザの別タブで開くと、作成したフォームが表示されます。
適当なデータを入力して「送信する」を押し、元のスプレッドシートの「転記先シート」にデータが追加されていれば成功です。

※実際の運用に合わせて、`index.html` の入力項目（`<input>`）と、`コード.gs` の `rowData` 配列の中身を調整してご使用ください。
