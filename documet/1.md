選択されているセルのデータを取得し、別のシート（表）の最終行にデータを追加するGoogle Apps Script（GAS）のコードを作成しました。

以下のコードは、現在選択している範囲のデータを取得し、「転記先シート」という名前のシートに1行ずつ追加するプログラムです。

### GASコード

``` javascript
function appendSelectedDataToTable() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  
  // 現在選択されているセル範囲を取得
  const activeRange = ss.getActiveRange();
  
  // 選択範囲のデータを取得（2次元配列）
  const values = activeRange.getValues();
  
  // 追加先のシートを指定（※実際のシート名に合わせて変更してください）
  const targetSheetName = "転記先シート";
  let targetSheet = ss.getSheetByName(targetSheetName);
  
  // 追加先のシートが存在しない場合はエラーメッセージを表示して終了
  if (!targetSheet) {
    SpreadsheetApp.getUi().alert(`エラー: 「${targetSheetName}」シートが見つかりません。シートを作成するか、コード内のシート名を変更してください。`);
    return;
  }
  
  // 取得したデータを1行ずつ追加先シートの最終行に追加
  for (let i = 0; i < values.length; i++) {
    const rowData = values[i];
    
    // 全てのセルが空白の行は追加しないようにする判定
    if (rowData.join("").trim() !== "") {
      targetSheet.appendRow(rowData);
    }
  }
  
  // 完了メッセージを表示
  SpreadsheetApp.getUi().alert("選択されたデータを表に追加しました。");
}

```

### 使い方

1.  スプレッドシートのメニューから **「拡張機能」 \> 「Apps Script」** をクリックしてエディタを開きます。
2.  最初から入力されている `function myFunction() { ... }` を消去し、上記のコードを貼り付けます。
3.  プロジェクトを保存（フロッピーディスクのアイコン、または `Ctrl + S` / `Cmd + S`）します。
4.  スプレッドシートに戻り、追加したいデータが入っているシート（例：「申込一覧」）を新しく作成した「転記先シート」を用意します。
5.  「申込一覧」シートで、転記したいデータ（例：`A4:J4` の行など）をマウスで選択状態にします。
6.  Apps Scriptのエディタ画面に戻り、上部の「実行」ボタンを押します。（※初回実行時は権限の承認ポップアップが表示されるので、画面の指示に従って許可してください）

**ポイント:**
現在の状態（`A1:J4`が選択されている状態）で実行すると、見出しや設定行も含めた4行分すべてが追加されてしまいます。純粋な申込データのみを追加したい場合は、実行前に **4行目（`A4:J4`）のみを選択** してからスクリプトを実行してください。
