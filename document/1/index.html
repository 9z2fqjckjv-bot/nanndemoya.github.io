ファイル全体の構成（全15シート以上）を読み込み、「4つのメインサービス ＋ オプション」の全料金体制を網羅した総合シミュレーターにアップグレードしたGASコードを作成しました。

このコードでは、スプレッドシートのタブ名（例：フリーサービス - 日中 や フリーサービス - オプション）を自動で解析し、「サービス名」「プラン（時間帯）」「給与形態」「単位」のプルダウンを動的に生成します。さらに、各サービスに付随する**「オプション」もチェックボックスで追加**して合計金額を算出できるようにしています。

以下の手順で コード.gs と Index.html を上書きしてください。

1. コード.gs（バックエンド）

すべてのシートをループ処理し、「基本料金」と「オプション料金」に分けてデータを抽出します。

function doGet() {
  return HtmlService.createHtmlOutputFromFile('Index')
      .setTitle('総合利用料金シミュレーター')
      .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL)
      .addMetaTag('viewport', 'width=device-width, initial-scale=1');

// 全シートから料金データを動的に取得する関数
function getFeeData() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheets = ss.getSheets();
  
  const result = {
    main: {},    // 基本料金表データ
    options: {}  // オプション表データ
  };

  sheets.forEach(sheet => {
    const sheetName = sheet.getName();
    // 「 - 」でサービス名とプラン名を分割
    const parts = sheetName.split(' - ');
    if (parts.length < 2) return;
    
    const serviceName = parts[0];
    const planName = parts[1];

    if (planName === 'オプション') {
      // オプションシートの処理 (A2:Dから取得)
      const data = sheet.getDataRange().getValues();
      result.options[serviceName] = [];
      for (let i = 1; i < data.length; i++) {
        if (data[i][0]) { // オプション名が存在する場合
          result.options[serviceName].push({
            name: data[i][0],
            desc: data[i][1],
            price: data[i][2],
            note: data[i][3]
          });
        }
      }
    } else {
      // 基本料金シートの処理 (日中, 夜間, プレミアム等)
      if (!result.main[serviceName]) {
        result.main[serviceName] = {};
      }
      result.main[serviceName][planName] = {};
      
      // A2:E6の範囲（料金表）を取得
      const data = sheet.getRange('A2:E6').getValues();
      const units = data[0].slice(1); // [1, 3, 6, 12]

      for (let i = 1; i < data.length; i++) {
        const type = data[i][0]; // 時間給, 日給, 週給, 月給
        if (!type) continue;
        result.main[serviceName][planName][type] = {};
        const fees = data[i].slice(1);
        for (let j = 0; j < units.length; j++) {
          result.main[serviceName][planName][type][units[j]] = fees[j];
        }
      }
    }
  });

  return result;
}

このコードの特長

  1. 完全自動追従: 今後スプレッドシート側に新しいサービス（例:新規サービス - 日中）や新しいオプションを追加しても、コードを書き換えることなく自動でプルダウンに反映されます。
  2. 連動型プルダウン: 「フリーサービス」を選ぶとそれに紐づくプラン（日中・夜間など）だけが表示され、あり得ない組み合わせを選択できないようになっています。
  3. オプション計算機能: 各サービス専用のオプションシート（例:フリーサービス - オプション）から「オプション名・説明・金額」を自動抽出し、チェックボックスで追加料金を合算できます。
