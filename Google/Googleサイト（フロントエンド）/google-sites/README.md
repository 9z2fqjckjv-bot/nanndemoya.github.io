# Google サイト最適化版

このフォルダは、`source/` の GitHub Pages 向け静的サイトを Google サイトへ移行するための作業領域です。

Google サイトは HTML/CSS/JavaScript の複数ファイルを通常の Web サイトのようには配置できないため、移行作業を次の単位に分けます。

- `pages/`: Google サイトの各ページへ移す本文断片
- `embeds/`: Google サイトの「埋め込む」で利用する HTML
- `shared/`: 埋め込み HTML 用の共通 CSS/JavaScript
- `drive-assets/`: Google ドライブへ置く資料・画像・動画
- `planning/`: ページ一覧、移行チェックリスト、URL 対応表
