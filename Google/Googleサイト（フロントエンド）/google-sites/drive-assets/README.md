# drive-assets

Google ドライブへ配置する資料・画像・動画用のフォルダです。

`documet/` には、元サイトの `source/documet/` から `.DS_Store` を除いた資料一式をコピーしています。

## 配置方針

- PDF、画像、動画は Google ドライブへ置き、共有リンクまたは Google サイトの Drive 挿入で表示します。
- Keynote、Numbers、Excel など編集元ファイルは管理用として保持し、公開ページでは PDF 版を優先します。
- 動画は Google サイトに直接 Drive 動画として挿入すると、スマートフォンでも扱いやすくなります。
