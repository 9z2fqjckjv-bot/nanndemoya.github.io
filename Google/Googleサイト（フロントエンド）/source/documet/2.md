**社内共有用ドキュメント案**

# Google Workspace AI Expanded Access 活用プラン提案書

**〜GAS × Google サイトによる低コスト・高セキュリティな Web ツール内製化〜**

## 1. 導入・活用の概要

本プラン（AI Expanded Access）で提供される **Gemini 3 / Nano Banana Pro などの高度な AI モデル** および **Workspace Studio** をフル活用し、外部委託せずに社内主導で「高機能なシミュレーター機能付き Web サイト（Google サイト＋GAS）」を開発・運用・拡張します。

---

## 2. 実現するシステム構成・開発活用イメージ

### 1) バックエンド開発の効率化（GAS × Gemini）

* **機密情報の完全隠蔽と処理実装**
* Google Maps API キーや計算ロジックなどの機密コードはすべて GAS（サーバー側）に保持。
* GAS エディタ内の Gemini アプリ連携を活用し、API 通信、距離・移動費用計算、スプレッドシート連携などのロジックをプロンプト指示で高速生成。


* **クォータ（上限）の緩和による開発スピード向上**
* AI Expanded Access の高度なアクセス枠により、途中で利用制限にかかることなく大容量・複雑なコードの自動作成やデバッグを実行。



### 2) フロントエンド・アナリティクス構成（Google サイト × タグ）

* **安全な画面構築**
* API キーを含まない設計（パターンA：API通信 / パターンB：iFrame埋め込み）により、Google サイト上に安全にシミュレーター要素を配置。


* **CV・行動ログの計測（Google タグ埋め込み）**
* GAS 側の HTML 内に Google アナリティクス（GA4）や Google 広告の gtag.js を組み込み、シミュレーション完了やフォーム送信などの重要イベントを直接発火・追跡。



### 3) 業務自動化の拡張（Workspace Studio）

* フォーム送信やシミュレーション結果の通知を受け取り、自動で指定の Gmail 送信やスプレッドシート整理、チャット通知を行うワークフローをノーコードで自動構築。

---

## 3. コスト・リソース面のメリット（検証結果）

* **ストレージ容量の最適化（30GB 枠で十分運用可能）**
* サイト本体や GAS コード、テキストデータはほぼ容量を消費せず、画像WebP化や外部ライブラリ（CDN）の活用により、最安プラン（30GB/ユーザー）の容量枠を圧迫しません（数MB〜数百MB程度で運用可能）。


* **開発・保守費用ゼロ化**
* 外部サーバー代や有料フォームサービスの契約が不要。
* システムの変更や機能追加（新サービス追加や料金改定など）も、Gemini アプリに修正コードを聞くだけで社内完結。



---

## 4. 期待される導入効果

1. **セキュリティの担保**：外部に公開したくないロジックや API キーを安全に保護してWebサービスを運用。
2. **広告・分析精度の向上**：GAS 埋め込み要素からのイベント発火により、Web 広告や集客施策のコンバージョン（CV）計測を正確化。
3. **内製化による大幅なコスト削減**：通常外注で数十万〜数百万円かかる開発・保守運用費用を月額の Workspace AI 利用料のみで実現。
