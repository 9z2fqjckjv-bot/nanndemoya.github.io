はじめに確認すること

利用したい内容が決まっている場合は、サービス一覧または料金シミュレーターで対象サービスと概算料金を確認してからお問い合わせください。内容が未確定の場合でも、フォームから相談できます。

サービスを選ぶ

子ども向け、シニア、フリー、アシスタント、ビジネスアシスタント、Nanndemoya365、NanndemoyaCloudなどから目的に近いものを確認します。

料金の目安を出す

基本料金、プレミアム料金、移動代金は条件によって変わります。各シミュレーターで事前に目安を確認できます。

主要5サービスとNanndemoya365の流れ

対象は、子ども向けサービス、シニアサービス、フリーサービス、アシスタントサービス、ビジネスアシスタントサービス、Nanndemoya365です。

  1. 申し込みフォームまたはお問い合わせフォームから、希望するサービス、日時、場所、依頼内容を送信します。
  2. 「何でも屋」から指定された連絡方法で返信し、対応可否、作業内容、料金条件を確認します。
  3. 内容が確定したら申し込み完了です。依頼日の前日までに、行きの移動代金をお支払いください。
  4. 依頼日当日、ご指定の場所でサービスを提供します。
  5. サービス終了後、利用料金とオプション料金をお支払いください。事前に支払った行きの移動代金は除きます。
  6. お支払い確認後、領収書をお渡しして完了です。

Nanndemoya365は、ベースパックでのお支払いが基本です。利用料金とオプション料金は、事前入金が必要になる場合があります。

定期利用・クラウドサービスの流れ

NanndemoyaCloud

  1. フォームから申し込みます。
  2. 見積書兼請求書を受け取り、記載された期限までに指定口座へ振り込みます。
  3. 入金確認後、利用開始手続きを行い、完了後に通知します。
  4. 初回以降は原則として毎月28日までにベースパックへ入金します。
  5. 入金確認後、サービス利用が継続されます。

MacStudioShere's

サービス提供開始後に、申し込み方法、利用条件、支払い方法を掲載します。

関連情報は、デジタルサービスの案内ページで確認できます。

MacStudioShere’sを見る

NanndemoyaCloudの初回支払いは銀行振り込み、初回以降はベースパックでのお支払いが基本です。

支援制度・何でも屋ハウスの流れ

ライフイベント支援

  1. フォームから支援内容を申し込みます。
  2. 対象要件を確認するための審査を行います。
  3. 審査通過後、指定された方法で入金状況を確認します。
  4. 「何でも屋」から連絡が届いた場合は、速やかに返信してください。

何でも屋ハウス

  1. 申し込みフォームから物件提供の希望を送信します。
  2. 詳細情報の確認依頼に返信します。
  3. 物件見学、査定、オプション確認の日時を調整します。
  4. 見学と査定、オプション項目の確認を実施します。
  5. 条件確認後、利用開始手続きに進みます。

何でも屋ハウスの査定は第三者の査定業者などが行う場合があるため、完了まで時間がかかることがあります。

お支払い方法

サービスの種類によって利用できる支払い方法が異なります。サブスクリプション形式のサービスや基金では、利用できる方法が限定される場合があります。

現金

何でも屋基金とサブスクリプション形式のサービス以外で利用できます。

口座振り込み

サブスクリプション形式のサービス以外で利用できます。NanndemoyaCloudの初回支払いにも使用します。

PayPal

サブスクリプション形式のサービス以外で利用できます。手数料の関係で割高になる場合があります。

ベースパッククレジット

主要サービスの基本料金に利用できます。オプション料金などには利用できない場合があります。

ベースパック

「何でも屋」の各サービスで利用できる前払い型の支払い方法です。

送金による支払い

サブスクリプション形式のサービスと何でも屋基金以外で利用できる場合があります。詳細はお問い合わせください。

ベースパックの特徴

  • 事前に入金した金額を、サービス利用時の支払いに活用できます。
  • 支払いを一本化しやすく、利用明細や電子領収書の確認に役立ちます。
  • 残高や条件に応じて、ベースパッククレジットが付与される場合があります。
  • 何でも屋基金への参加や、関連サービスの支払い管理にも活用できます。
